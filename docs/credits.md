# Благодарности

Формат обмена описан в [OpenVader](https://github.com/FilipVajgand/openvader/blob/main/docs/PROTOCOL.md) и [flydigi-vader-pro-5-ctl](https://github.com/rR6kULhc5xgS/flydigi-vader-pro-5-ctl/blob/main/docs/protocol-rgb-mapping.md).
