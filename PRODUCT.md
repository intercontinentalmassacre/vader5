# Vader 5 Pro

Русскоязычное приложение для владельца Flydigi Vader 5 Pro на Windows и Linux. Первая задача — переназначать кнопки и лепестки в активном профиле контроллера. Пользователь видит фактические назначения, меняет их и сам решает, когда записать изменения в устройство.

## Platform

Нативное настольное приложение для Windows и Linux, Rust и egui. Первое подключение через USB или приёмник.
